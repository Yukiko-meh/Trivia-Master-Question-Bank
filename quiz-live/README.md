# 小小知識王(多人即時排行榜版)

大家掃同一個 QR 碼,作答相同的題目(每人順序不同),完成後看到全部人的排行榜。

## 怎麼玩
1. 主辦人開首頁,選年級和題數,按「建立比賽」。
2. 畫面出現 QR 碼,投影或印出來。按「開啟大螢幕排行榜」可在大螢幕即時顯示名次。
3. 參加者掃 QR 碼,輸入暱稱,作答。答完自動送出成績並看到排行榜。
4. 排名:答對題數多的在前,同分比總作答時間,短的在前。

## 部署到 Vercel
1. 在 Vercel 匯入這個 GitHub 儲存庫,**Root Directory 選 `quiz-live`**。
2. 到專案的 Storage 頁,從 Marketplace 加入 **Upstash Redis**(免費額度即可),連到這個專案。
   會自動新增環境變數 `KV_REST_API_URL`、`KV_REST_API_TOKEN`。
3. 重新部署一次(Redeploy),完成。

沒有設定 Redis 時,伺服器會用記憶體暫存成績。這只適合測試,成績可能隨時消失。

## 檔案
- `public/index.html` 整個前端(建立比賽、作答、排行榜)
- `public/questions.js` 題庫與抽題邏輯,前後端共用
- `api/submit.js` 收成績,由伺服器對照題庫重新算分
- `api/board.js` 回傳排行榜
- `api/_store.js` 儲存層(Upstash Redis REST)

## 注意
- 房間代碼寫在網址裡,題目由代碼決定,所以不需要先在伺服器建立房間。
- 成績保存 14 天。
- 題庫放在公開儲存庫,比賽前題目並不保密。
